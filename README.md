# مستودع تحديثات زاد القلوب | Zad Al Qulub Updates

هذا المستودع العام مخصص حصرياً لتوزيع ملفات التعريف بالبيانات الوصفية (Metadata) لمركز التحديثات الذكي لتطبيق وموقع **زاد القلوب**.

## المحتويات:
- `manifest.json`: ملف التحديثات الرسمي للإنتاج (Production Update Manifest).
- `manifest-test.json`: ملف التحديثات التجريبي لاختبارات دورة التحديث.
- `release-notes/`: سجل التغييرات الرسمي لكل إصدار بالعربية والإنجليزية.

## الروابط الثابتة عبر GitHub Pages:
- الإنتاج: `https://youssefali2002.github.io/zad-al-qulub-updates/manifest.json`
- الاختبار: `https://youssefali2002.github.io/zad-al-qulub-updates/manifest-test.json`

## ضوابط الأمان:
- لا يحتوي هذا المستودع على الكود المصدري الأصلي للتطبيق (المحفوظ في مستودع خاص منفصل).
- لا يحتوي على أي مفاتيح تشفير أو شهادات توقيع أو أسرار.
- جميع حزم الـ APK المنشورة عبر GitHub Releases تخضع للتحقق من بصمة التجزئة SHA-256 قبل تثبيتها على أجهزة المستخدمين.
